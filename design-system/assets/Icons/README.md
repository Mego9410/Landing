# Icons

Original 24px line set: 2px stroke, round caps and joins, no fills, corners softened to match `radius-sm`. Single ink `ink` #2E2A33 as drawn; in the app, render them as inline SVG with `stroke="currentColor"` so they take the text colour.

- `today.svg` — Today tab (a low sun).
- `plan.svg` — Plan tab (a winding path between two points).
- `progress.svg` — Progress tab (a gentle trend line on a baseline).
- `coach.svg` — Coach tab (a rounded speech bubble).
- `check.svg` — Habit done, saved confirmations.
- `plus.svg` — Quick log.
- `workout.svg` — Strength sessions.
- `hunger.svg` — Hunger rating (a bowl).
- `reset.svg` — Reset week.
- `protein.svg` — Protein logging.

Never use a bathroom scale, tape measure or flame icon: weight is one number among several here, and "burn" language is off-brand.
