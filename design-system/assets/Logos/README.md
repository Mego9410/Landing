# Logos

- `landing-mark.svg` — The mark: an apricot sun touching down on a sage horizon, with two trail dots showing its gentle descent. Two fixed inks (`apricot` #F8C8AC, `sage` #CDE3D2 light values); never recolour, never outline. Use it alone at 24px and up.
- `landing-wordmark.svg` — Monoline lowercase "landing", always lowercase. Single ink `ink` #2E2A33; on dark grounds swap the stroke to `ink` dark (#F3EEF4) in code.
- `landing-lockup.svg` — Mark plus wordmark, for the waitlist site, App Store screenshots and the prescriber pack header. Clear space on every side = the sun's diameter.
- `app-icon.svg` — 1024px square App Store icon source on `surface` oat. Export to PNG; iOS applies the rounded mask, so keep the square full-bleed.

"Landing" is a working name pending trademark and App Store checks; every file here is named so a rename only touches the wordmark.
