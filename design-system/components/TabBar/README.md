# TabBar

The four-tab bar: Today, Plan, Progress, Coach, with the active tab in an apricot pill (lilac for Coach).

- Provide: `active`, `onChange(key)`; `items` only if the tabs change.
- Floats above the home indicator with `space-3` side margins and `shadow-sm`.
- Labels are always shown. The quick-log sheet opens from a button on Today, not from the tab bar.
