# Logos

- `steadie-mark.svg` — The mark: an apricot sun touching down on a sage horizon, with two trail dots showing its gentle descent. Two fixed inks (`apricot` #F8C8AC, `sage` #CDE3D2 light values); never recolour, never outline. Use it alone at 24px and up.
- `steadie-wordmark.svg` — Monoline lowercase "steadie", always lowercase. Single ink `ink` #2E2A33; on dark grounds swap the stroke to `ink` dark (#F3EEF4) in code.
- `steadie-lockup.svg` — Mark plus wordmark, for the waitlist site, App Store screenshots and the prescriber pack header. Clear space on every side = the sun's diameter.
- `app-icon.svg` — 1024px square App Store icon source on `surface` oat. Export to PNG; iOS applies the rounded mask, so keep the square full-bleed.

The app was called "Landing" before it became Steadie; the mark (a sun settling on a horizon) carried over unchanged.
