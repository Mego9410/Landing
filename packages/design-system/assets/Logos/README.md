# Logos

The Steadie symbol is the **roly-poly**: a self-righting shape, mid-tilt, with its weight sitting low (the dot), so
whatever nudges it, it rocks back upright. The full spec, colours and rules are in [`../../brand/README.md`](../../brand/README.md).

**The mark** (viewBox `22 18 56 76`; the dot is knocked out, so the background shows through):
- `steadie-mark-apricot.svg`: the default, on light and oat backgrounds.
- `steadie-mark-light-on-dark.svg`: #F2A27A, on dark backgrounds.
- `steadie-mark-cream.svg`: on apricot backgrounds.
- `steadie-mark-cocoa-mono.svg`: one colour, for example greyscale print.

**The wordmark and lockup**: lowercase "steadie" in Nunito 800 at −0.035em, with the "i" dot replaced by the weight dot.
These are outlined from the font, so they look the same everywhere, including where Nunito isn't loaded. They're
generated from the designer's typeset reference (`wordmark-reference.html`), measured in a browser.
- `steadie-wordmark.svg` / `steadie-lockup.svg`: ink #2A2530 with an apricot dot and mark, on light.
- `-on-dark`: oat text, #F2A27A dot and mark, on dark.
- `-cream`: cream text, dot and mark, on apricot.
- `-mono`: all ink.

Lockup proportions: mark height ≈ 1.15 × the wordmark's font size, gap ≈ 0.26 ×. Clear space is the width of the mark
on every side. Minimum size: wordmark 16 px, mark 18 px tall. Below 24 px, drop the ground line and centre the body.

**The app icon**: `steadie-app-icon-1024.svg` and `.png` (1024 × 1024, opaque, no text, square corners: iOS applies
the mask). Tile #DE6F44, body #FBF1E4. Sizes for asset catalogues are in `../../brand/app-icon-sizes/`.

Don't: outline, add gradients or shadows to, recolour the dot of, mirror or straighten the mark, or add a face. The
mark always leans left.
