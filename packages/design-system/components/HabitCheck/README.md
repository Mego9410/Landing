# HabitCheck

One of the week's three habits on the Today tab, ticked with a round check that fills the row with `sage`.

- Provide: `label`, optional `detail` (target or progress), `checked`, `onChange(checked)`.
- Always exactly three on Today, stacked with `space-3` gaps.
- Ticking gives a soft pop and a light haptic. Unticking is silent; never show a "streak lost" message.
- Labels are actions in sentence case: "Protein at breakfast", "Walk after dinner".
