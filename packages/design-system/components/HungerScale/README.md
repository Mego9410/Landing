# HungerScale

A five-step hunger rating for the quick-log sheet: five round buttons, the chosen one filled `sky`.

- Provide: `value` (1–5), `onChange(value)`, optional `label`, `lowLabel`, `highLabel`.
- 1 is "Very hungry", 5 is "Comfortably full". Keep those words; they're used in the score maths.
- No faces or emoji on the steps. Logging must take under 10 seconds, so no confirmation step.
