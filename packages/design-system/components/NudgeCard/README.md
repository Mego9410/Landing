# NudgeCard

The early-warning card: a calm `butter` card offering a reset week when drift is detected.

- Provide: `title`, `children` (one or two sentences), optional `actionLabel` and `onAction`.
- Appears on Today and Progress when the early warning fires. One at a time; dismissible.
- Copy rules: name the change gently, normalise it, offer one simple step. Never quote the percentage, never say "regain", never suggest eating less.
- Never use it for errors. Form errors use `rose-ink` text under the field.
