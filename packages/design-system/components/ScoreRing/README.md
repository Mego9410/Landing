# ScoreRing

The weekly steady score (0–100) as a soft ring with the number in the middle.

- Provide: `score`, optional `size` (default 168) and `label` (default "Steady score").
- The ring is always `sage`. Never colour the score red, amber or green by value: the score rewards consistency and should never feel like a grade.
- Pair it with one plain sentence about what moved it: "Habits carried you this week."
- In safe mode the score still shows; the copy never mentions weight.
